# mdhafizur.github.io

Personal engineering portfolio of **Md Hafizur Rahman**, Senior Full-Stack Engineer in Bamberg, Germany.

Live at **https://mdhafizur.github.io**

- Case studies with a technical overview, architecture diagram, scale and key decisions for each project
- Experience timeline and education
- Technical blog posts

## Editing

Everything is in one file, `index.html`, with no build step.

- **Profile, experience and case studies:** the `SITE` object in the last `<script>` block.
- **Blog posts:** each post is a `<script type="text/markdown">` block near the top. Copy one and change `data-slug`, `data-title`, `data-date` and `data-summary`.

Commit and push to `main`. GitHub Pages republishes within about a minute.
